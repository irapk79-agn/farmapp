\# Farm Management System



A Django-based system for managing a 100-block agricultural land with

per-row crop tracking, harvest history, and multi-role access.



\## 🚀 Live Site

https://paari.pythonanywhere.com



\## 🏗️ Tech Stack

\- Django 5.2

\- SQLite (dev + prod)

\- PythonAnywhere (hosting)

\- Django templates + minimal JavaScript
